## [v0.5.1] — 2026-10-20

### 🚀 Исправления и улучшения стабильности (TLS/HTTPS и I2C):
- **Стабилизация TLS/HTTPS для GitHub OTA (исправление ошибки -1):**
  - **Отключение энергосбережения Wi-Fi:** вызов `WiFi.setSleep(false)` при подключении к сети предотвращает микрозасыпания радиомодуля ESP32-C6 и сбросы TCP-сокетов во время криптографических операций.
  - **Автоматическое отключение SoftAP:** вызов `WiFi.enableAP(false)` при переходе в режим STA для освобождения радиоресурсов и стабильности канала.
  - **Чистое разделение TLS-сессий при скачивании релиза:** при HTTP 302 редиректе с `github.com` на CDN `objects.githubusercontent.com` модуль `OtaGithub` перехватывает заголовок `Location`, закрывает исходную сессию и создает новый чистый экземпляр `WiFiClientSecure` непосредственно к целевому хосту скачивания `firmware.bin` (полное устранение ошибки -1 при смене SNI/хоста).
  - **Увеличенные таймауты и повторы:** таймаут TLS-рукопожатия и сокета увеличен до 15 с, добавлены 3 автоматические попытки при коде соединения `< 0`.
  - **Стабилизация загрузки эффектов в `StoreManager`:** унифицированный загрузчик `downloadFile` с таймаутом 15 с и 3 попытками повтора при ошибках сети.
- **Глубокая диагностика шины I2C и расширенный авто-поиск GY-521:**
  - **Контроль электрических уровней линий:** проверка SDA/SCL до запуска I2C (`digitalRead` в режиме `INPUT`). При `LOW` формируется точный диагноз отсутствия питания 3.3V или подтягивающих резисторов на плате GY-521 (`No pull-up / Check 3.3V on GY-521`).
  - **Расширенный авто-поиск по свободным пинам:** при отсутствии ответа на GPIO 6 / GPIO 5 выполняется перебор пар среди `GPIO 4, 5, 6, 8, 9` на адресах `0x68` и `0x69` на случай сдвига маркировки/шелкографии на платах ESP32-C6.
  - **Информативная телеметрия:** подробный статус выводится в `/api/status` и на панели телеметрии WebUI.

## [v0.5.0] — 2026-10-20

### 🚀 Новые возможности и архитектура Магазина эффектов (GitHub Effect Store):
- **Файловая система LittleFS & StoreManager:**
  - Монтирование встроенного раздела `littlefs` (~428 КБ) с сохранением существующего `partitions.csv` (100% совместимость с Silent OTA с версии v0.4.0).
  - Модуль `StoreManager` (`src/network/store_manager.*`): авто-сканирование каталога `/effects/*.eff`, безопасная загрузка по HTTPS с GitHub Raw (`setInsecure()` + `HTTPC_STRICT_FOLLOW_REDIRECTS`), валидация и удаление эффектов.
- **Движок подгружаемых эффектов `EffectVM`:**
  - Интерпретатор компактных дескрипторов эффектов `.eff` с настраиваемыми палитрами, масштабом, скоростью и интенсивностью.
  - 6 аппаратных ядер рендеринга на бесшовном цилиндре 16x16 (60 FPS):
    1. **Северное сияние (`aurora`)** — волнообразные ленты с шумом Перлина в изумрудно-бирюзовых и фиолетовых тонах.
    2. **Матрица (`matrix_rain`)** — каскадный цифровой зеленый дождь со шлейфами.
    3. **Лава-лампа (`lava_lamp`)** — тепловая конвекция восковых капель с субпиксельным слиянием.
    4. **Галактика (`vortex`)** — трехрукавная спираль вокруг цилиндра.
    5. **Фейерверк (`fireworks`)** — взлетающие ракеты и гравитационный разлет искр.
    6. **Кибер-пульс (`cyber_pulse`)** — неоновые кольца Synthwave и волновой шейдер с реакцией на звук.
- **Динамическая регистрация в `EffectManager`:**
  - Поддержка до 24 эффектов (10 базовых 0..9 + динамические 10..N из LittleFS).
  - Бесшовное циклическое переключение двойным кликом кнопки и через WebUI.
  - Мгновенная активация скачанного эффекта без перезагрузки лампы.
- **Обновленный WebUI и REST API:**
  - Эндпоинты `/api/store/installed`, `/api/store/catalog`, `/api/store/install`, `/api/store/delete`.
  - В `/api/status` добавлен динамический массив `effects` и общее число `totalEffects`.
  - Динамическая отрисовка кнопок всех эффектов в пульте управления.
  - Секция «Магазин эффектов (GitHub Effect Store)» в веб-интерфейсе: индикатор памяти LittleFS, карточки каталога с GitHub Raw, кнопки «Скачать в лампу», «Включить», «Удалить».
- **Витрина каталога в репозитории (`store/`):**
  - Каталог `store/manifest.json` и 6 готовых эффектов `store/effects/*.eff` доступны для скачивания напрямую в лампу.

## [v0.4.0] — 2026-10-20

### 🚀 Новые возможности и улучшения:
- **Индикация пределов яркости и нелинейный диммер:**
  - Однонаправленная регулировка яркости при удержании сенсорной кнопки (`LONG_PRESS_HOLD`): яркость изменяется в одну сторону до упора (`MIN = 12`, `MAX = 255`) без отката назад до отпускания кнопки.
  - Нелинейный шаг (гамма-коррекция): плавный шаг (2–3 ед.) в темных тонах и ускоренный (5–7 ед.) в светлых для визуальной равномерности.
  - Световая отсечка пределов: при достижении `MAX (255)` верхнее кольцо матрицы (`Y=15`) дважды коротко вспыхивает белым светом; при достижении `MIN (12)` нижнее кольцо (`Y=0`) дважды коротко вспыхивает бирюзовым цветом (`CRGB(0, 255, 200)`).
- **Обновленный эффект «Костер» (`Fire`):**
  - Высота пламени сбалансирована на 3/4 лампы (`Y = 0..10`), верхняя четверть (`Y = 11..15`) темная.
  - Добавлена система одиночных ярких взлетающих искр (`FireSpark`), плавно улетающих в темную верхнюю зону с легким затухающим шлейфом.
- **Интеллектуальный авто-поиск пинов I2C для GY-521:**
  - Автоматическое сканирование адресов `0x68` и `0x69` на основной паре пинов `SDA = GPIO 6, SCL = GPIO 5` (100 кГц, `INPUT_PULLUP`).
  - При отсутствии ACK на основной паре выполняется автоматический реверс шины на `SDA = GPIO 5, SCL = GPIO 6` (защита от ошибок монтажа/пайки).
  - Фоновое периодическое авто-сканирование (каждые 5 сек) в режиме Fallback.
  - Подробный статус шины транслируется в `/api/status` и отображается в WebUI (`Online (SDA:6, SCL:5, addr:0x68, who:0x..)` или `Not Found on GPIO 5/6`).
- **Информативная диагностика GitHub OTA:**
  - При ответе сервера с HTTP 404 (до первого опубликованного релиза) лампа корректно сообщает: *"Релизов на GitHub пока нет (HTTP 404)"*.

## [v0.3.0] — 2026-10-20

### 🚀 Новые возможности:
- **Встроенный Web-интерфейс (`WebUI`):**
  - Автономный одностраничный веб-пульт в `PROGMEM` по адресу `http://magiclamp.local`.
  - Управление питанием, ползунки яркости, скорости и чувствительности микрофона, выбор всех 10 эффектов.
  - Телеметрия: температура CPU ESP32-C6, RSSI, свободный Heap, статус гироскопа.
  - Модуль OTA-обновления: кнопка проверки обновлений с GitHub и веб-форма для прямой заливки `firmware.bin`.
- **Модуль беспроводного обновления GitHub Silent OTA:**
  - Неблокирующая фоновая проверка `https://api.github.com/repos/gaterkik/MagicLamp/releases/latest`.
  - Автоматическая обработка HTTP 302 редиректов и скачивание `firmware.bin` во второй слот flash-памяти.
- **Wi-Fi Менеджер и Captive Portal:**
  - Автоматическое подключение по сохраненным данным NVS / `secrets.h`.
  - Точка доступа `MagicLamp-Setup` (192.168.4.1) с Captive Portal при отсутствии связи с роутером.
  - Поддержка сетевой прошивки `ArduinoOTA` по локальной сети.

## [v0.2.0] — 2026-10-19

### 🚀 Новые возможности:
- **10-й эффект «Светлячки» (`Fireflies`):** 15 светлячков с субпиксельными координатами, билинейным сглаживанием на бесшовном цилиндре и индивидуальными циклами яркости.
- **Аудио АРУ (AGC) и шумоподавитель:** адаптивное усиление микрофона INMP441 со спектральным анализом FFT.
- **Драйвер GY-521 с толерантностью к клонам:** поддержка любых идентификаторов `WHO_AM_I` при наличии I2C ACK.
- **Сенсорная кнопка TTP223:** 5-кратный клик для сетевого сброса, удержание с тиками 40 мс для регулировки яркости.

## [v0.1.0] — 2026-10-18

### 🚀 Базовый релиз:
- Аппаратный скелет на ESP32-C6: драйверы WS2812B (FastLED), TTP223, INMP441 (I2S DMA), GY-521 (I2C).
- Базовый движок эффектов: Ночник, Рассвет/Закат, Костер, Шум Перлина, Игра Жизнь, Аттрактор Лоренца, Метаболы, Песочные часы, Реакция на звук.
- Сохранение настроек в энергонезависимую память NVS (Preferences).
