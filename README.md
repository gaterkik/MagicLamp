# MagicLamp 🪄💡

Умная настольная цилиндрическая светодиодная лампа на базе микроконтроллера **ESP32-C6 (RISC-V)** с адресной матрицей 16x16 (256 LED WS2812B), аппаратным спектральным анализом звука (I2S DMA + FFT + АРУ), физической симуляцией сыпучих частиц по гироскопу (GY-521 / MPU-6050), встроенным адаптивным WebUI и бесшумным обновлением прошивки напрямую с GitHub Releases (Silent OTA).

---

## 🌟 Основные возможности

- **10 зрелищных визуальных эффектов** с честным бесшовным цилиндрическим рендерингом на 60 FPS.
- **Интерактивная физика песка:** частицы в эффекте «Песочные часы» реагируют на реальный наклон и вращение лампы благодаря 6-осевому гироскопу/акселерометру GY-521 с авто-определением пинов I2C.
- **Музыкальная визуализация:** цифровой I2S микрофон INMP441, аппаратный DMA-захват, 128-точечное быстрое преобразование Фурье (FFT), автоматическая регулировка усиления (АРУ / AGC) и адаптивный шумоподавитель (Noise Gate).
- **Плавное и интуитивное сенсорное управление:** емкостная кнопка TTP223 с поддержкой кликов, мульти-кликов, удержания с гамма-коррекцией и световой индикацией достижения границ яркости.
- **Встроенный WebUI (http://magiclamp.local):** полностью автономный пульт управления и телеметрия реального времени (температура процессора ESP32-C6, уровень сигнала Wi-Fi, статус сенсоров, аптайм, память).
- **Беспроводное автообновление (Silent GitHub OTA):** лампа сама проверяет наличие новых версий на GitHub (`gaterkik/MagicLamp`), скачивает `firmware.bin` и обновляется по воздуху без подключения проводов.
- **Энергобезопасность:** жесткий программный лимит потребления тока в **2500 мА** на уровне FastLED для защиты блока питания и компонентов.

## 🛠 Аппаратная спецификация и распиновка (Pinout)

- **Микроконтроллер:** ESP32-C6 Mini (RISC-V, 160 МГц, 4 МБ Flash, Wi-Fi 6, Bluetooth 5, Zigbee/Thread).
- **Питание:** Внешний импульсный БП 5V / 3.0A.
- **Светодиодная матрица:** 16×16 WS2812B (256 LED), свернутая в цилиндр. DIN подключен снизу (`Y=0`), змейка горизонтальная, координата `X` замкнута в кольцо.

| Устройство | Назначение / Линия | Пин ESP32-C6 | Примечания |
| :--- | :--- | :--- | :--- |
| **LED-матрица 16x16** | `DIN` (Data In) | **GPIO 2** | Токоограничивающий резистор 330–470 Ом на линии данных |
| **Кнопка TTP223** | `I/O` (Out) | **GPIO 7** | Высокий уровень (HIGH) при касании сенсора |
| **Гироскоп GY-521** | `SDA` / `SCL` | **GPIO 6 / GPIO 5** | I2C (100 кГц). Поддерживается авто-реверс пинов (5 и 6) |
| **Микрофон INMP441** | `SCK` (BCLK) | **GPIO 18** | Тактовая линия аудио I2S |
| **Микрофон INMP441** | `WS` (LRCLK) | **GPIO 19** | Выбор аудиоканала (Word Select) |
| **Микрофон INMP441** | `SD` (Data) | **GPIO 20** | Линия данных I2S |
| **Питание компонентов** | `5V` / `GND` | `5V` / `GND` | Общая земля для всех модулей обязательна |

## 👆 Управление сенсорной кнопкой

Сенсор TTP223 скрыт в верхней крышке лампы под рассеивателем:

- **1 клик (Single Click):** Включение или плавное выключение лампы с сохранением состояния в NVS.
- **2 клика (Double Click):** Переключение на следующий эффект по кругу (1 → 2 → ... → 10 → 1).
- **Удержание (от 700 мс, Hold):** Плавное изменение яркости в реальном времени с нелинейным шагом (комфортно для глаза на любом уровне).
  - При удержании яркость меняется строго в одну сторону до упора (MIN: 12, MAX: 255) и не разворачивается, пока палец не отпущен.
  - При каждом следующем удержании направление меняется на противоположное.
  - **Визуальная отсечка предела:** при достижении максимума (255) верхнее кольцо лампы (`Y=15`) дважды вспыхивает белым светом. При достижении минимума (12) нижнее кольцо (`Y=0`) дважды вспыхивает бирюзовым цветом.
- **3 клика (Triple Click):** Принудительная проверка наличия обновления прошивки на GitHub и Silent OTA.
- **5 кликов подряд (Five Clicks):** Сброс настроек Wi-Fi и перевод лампы в режим точки доступа сопряжения (`MagicLamp-Setup`).

## 🎨 Каталог эффектов

1. **Ночник (`Nightlight`):** Мягкое теплое свечение 2700K с едва уловимым естественным дыханием.
2. **Рассвет / Закат (`DawnDusk`):** Суточный световой цикл восхода и захода солнца по местному времени GMT+2.
3. **Костер (`Fire`):** Густое, тягучее живое пламя высотой в 3/4 лампы (`Y=0..10`) с субпиксельной интерполяцией и отдельной системой одиночных ярких искр, улетающих в темную верхнюю зону (`Y=11..15`).
4. **Шум Перлина (`PerlinNoise`):** Органические бесшовные облака плазмы в полярных координатах цилиндра.
5. **Игра «Жизнь» (`GameOfLife`):** Клеточный автомат Джона Конвея, замкнутый по кольцу, с автоперезапуском при вырождении и реакцией на встряхивание лампы.
6. **Аттрактор Лоренца (`LorenzAttractor`):** 3D-траектория классической системы странного аттрактора с неоновым шлейфом.
7. **Метаболы (`Metaballs`):** Пять светящихся органических сфер, плавно взаимодействующих и сливающихся друг с другом.
8. **Песочные часы (`SandHourglass`):** Около 100 песчинок с реальной физикой падения и пересыпания под действием вектора гравитации с датчика GY-521.
9. **Реакция на звук (`AudioReactive`):** 16-полосный спектроанализатор с микрофона INMP441 с автоматической подстройкой под громкость музыки и басовыми круговыми всплесками.
10. **Светлячки (`Fireflies`):** 15 лесных светлячков теплых золотистых и лаймовых оттенков с дробными координатами, плавным билинейным сглаживанием и индивидуальным циклом свечения.

## 🌐 Веб-интерфейс (WebUI)

При подключении лампы к вашей Wi-Fi сети откройте в браузере:
👉 **[http://magiclamp.local](http://magiclamp.local)** (или IP-адрес лампы, выданный роутером).

### Возможности интерфейса:
- Включение / выключение питания лампы.
- Ползунки плавной настройки яркости, скорости эффекта и чувствительности микрофона.
- Кнопки быстрого выбора каждого из 10 эффектов.
- **Панель телеметрии:**
  - Температура процессора ESP32-C6 (°C);
  - Уровень Wi-Fi сигнала (RSSI dBm);
  - IP-адрес и mDNS-имя;
  - Время непрерывной работы (Uptime);
  - Свободная оперативная память (Heap);
  - Диагностика и авто-определение шины датчика GY-521 (`Online (SDA:6, SCL:5, addr:0x68)` / `Not Found`);
  - Текущая версия прошивки (`FIRMWARE_VERSION`).
- **Центр обновлений:** кнопка онлайн-проверки обновлений с GitHub и форма прямой загрузки `firmware.bin` из файла.

## 📶 Первое подключение к Wi-Fi

1. При первом включении (или после 5-кратного клика) лампа создаст собственную сеть Wi-Fi: **`MagicLamp-Setup`** (без пароля).
2. Подключитесь к этой сети со смартфона или ноутбука — автоматически откроется окно авторизации (Captive Portal). Если окно не открылось, перейдите в браузере по адресу `http://192.168.4.1`.
3. Выберите вашу домашнюю Wi-Fi сеть, введите пароль и сохраните настройки.
4. Лампа подключится к роутеру и будет доступна по адресу `http://magiclamp.local`.

## 🚀 Обновление по воздуху (Silent GitHub OTA)

Лампа оснащена встроенным клиентом GitHub Releases:
- При запуске (через 30 секунд), каждые 30 минут в фоне, по 3-кратному нажатию кнопки или по клику в WebUI лампа опрашивает `https://api.github.com/repos/gaterkik/MagicLamp/releases/latest`.
- Если номер тега релиза новее текущего `FIRMWARE_VERSION` — прошивка автоматически скачивает файл `firmware.bin` в соседний OTA-раздел флеш-памяти и перезагружается.

## 💻 Сборка из исходников (PlatformIO)

### Требования:
- [PlatformIO Core](https://platformio.org/) или расширение PlatformIO для VS Code.
- Платформа Espressif 32 с поддержкой ESP32-C6 (в `platformio.ini` настроен современный `pioarduino/platform-espressif32`).

### Команды:
```bash
# Клонирование репозитория
git clone https://github.com/gaterkik/MagicLamp.git
cd MagicLamp

# Сборка проекта
pio run

# Прошивка через USB Type-C
pio run --target upload

# Монитор порта (115200 бод)
pio run --target monitor
```
