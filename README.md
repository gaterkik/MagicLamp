# MagicLamp 🪄💡

Умная настольная цилиндрическая светодиодная лампа на базе микроконтроллера **ESP32-C6 (RISC-V)** с адресной матрицей 16x16 (256 LED WS2812B), аппаратным спектральным анализом звука (I2S DMA + FFT + АРУ), физической симуляцией сыпучих частиц по гироскопу (GY-521 / MPU-6050), встроенным адаптивным WebUI и бесшумным обновлением прошивки напрямую с GitHub Releases (Silent OTA).

---

## 🌟 Основные возможности

- **16 встроенных нативных эффектов** с честным бесшовным цилиндрическим рендерингом на 60 FPS (10 классических + 6 дополнительных нативных C++ эффектов).
- **Регулировка цветовой температуры Ночника (`Nightlight`):** индивидуальный слайдер в карточке WebUI от янтарно-свечного (1800K, `B=0`) через теплый ламповый (2700K) до мягкого нейтрально-белого (4000K).
- **Реальная аудио-реактивность Киберпанк-пульс (`CyberPulse`):** 16 частотных полос FFT (`mic.getBand(0..15)`) динамически модулируют высоту неоновых столбиков, а детектор басового бита (`mic.isBeat()`) запускает расходящиеся взрывные ударные кольца от центра матрицы (`Y=7..8`) к краям. В тишине — плавное неоновое кибер-дыхание.
- **Потокобезопасный Silent OTA (без коллизий RMT):** фоновая загрузка FreeRTOS задачи передает статус в `EffectManager`, а вся отрисовка матрицы выполняется строго в основном цикле `loop()`. Это гарантирует 100% стабильность прошивки по воздуху без аппаратных сбоев RMT-драйвера ESP32-C6.
- **Бесшумный ночной OTA (Stealth Mode) и радар-поиск:**
  - Если обновление запускается при выключенной лампе, светодиодная матрица остается ПОЛНОСТЬЮ темной (0% свечения, без вспышек и шкал), а после перезагрузки лампа остается выключенной.
  - При 3 кликах сенсорной кнопки отображается анимация поиска: по верхнему кольцу ($Y=15$) вращается бело-голубой луч-радар. При отсутствии обновлений кольца $Y=14..15$ дважды мигают изумрудно-зеленым светом; при наличии новой версии — плавная шкала 0..100% снизу вверх.
- **Независимый системный Будильник Рассвет и Таймер Отбой (Интуитивная логика времени):**
  - Расписание работает поверх любого выбранного эффекта и даже когда лампа выключена. Время задает момент **завершения** сценария.
  - **Будильник («Рассвет»):** настраиваемая длительность (5, 10, 15, 30 мин, по умолчанию 5 мин) до целевого времени. Лампа включается из состояния `OFF` и плавно разгорается от утренних углей до 100% теплого солнца к назначенному часу.
  - **Таймер сна («Отбой»):** за 15, 30 или 45 минут (по умолчанию 30 мин) до времени отбоя лампа перехватывает управление у любого эффекта, переходит в безопасный для сна янтарный режим 1900K (строго $B = 0$, без синего спектра) и плавно угасает ровно к целевому времени до полного выключения.
  - **Кнопка «Заснуть сейчас (Таймер сна)»:** мгновенный запуск янтарного затухания в один клик без необходимости настраивать время на часах.
  - **Живые часы и статус:** отображение текущего времени (`GMT+2`) и цветовой индикатор активной фазы в WebUI.
- **Умная автоматика и контрастная индикация Wi-Fi <-> Zigbee (Яндекс Станция / Алиса):**
  - **Переход в Wi-Fi:** Горизонтальное вращение ярко-зеленого/лазурного маяка по верхним кольцам ($Y=14..15$) в течение 1.8 с.
  - **Переход в Zigbee:** Вертикальное схождение колец сверху и снизу к экватору ($Y=7..8$) со вспышкой пурпурно-золотого цвета и мягким «дыханием» Алисы.
  - При старте лампа включает Wi-Fi на 60 секунд (NTP GMT+2 и проверка OTA). Любое обращение к WebUI продлевает сеанс Wi-Fi на 10 минут. При отсутствии веб-активности лампа автоматически переходит в Zigbee.
  - Раз в сутки в 04:00 (GMT+2) автоматически открывается окно Wi-Fi на 45 секунд для проверки обновлений в Stealth Mode.
  - 4 клика по кнопке TTP223 принудительно включают Wi-Fi на 10 минут. Поддержка команд Алисы (вкл/выкл, яркость, выбор любого из 16 эффектов по оттенку).
- **Физический UX уровня Apple:**
  - Плавный кроссфейд (500 мс) со смешиванием кадров `CRGB::blend()` при любом переключении эффектов.
  - Анимация шторки включения лампы (мягкая волна снизу вверх `Y=0..15` за 600 мс) и выключения (плавное угасание сверху вниз `Y=15..0` за 600 мс).
- **Интерактивные карточки эффектов, независимое расписание и избранное для кнопки (Accordion UI):**
  - Шапка WebUI освобождена от общих регуляторов: отдельная панель глобального расписания и список из 16 карточек-аккордеонов с индивидуальными настройками.
  - Чекбоксы «В цикле кнопки» (`inCycle`) на каждой карточке (сохраняются в NVS). Двойной клик физической кнопки переключает только отмеченные эффекты.
- **Безопасный спектр для сна (Отбой):** в режиме отхода ко сну категорически запрещена синяя компонента (`B = 0`), используется исключительно теплый свечной/янтарный свет (~1900K, `CRGB(r, r*0.28, 0)`), безопасный для выработки мелатонина.
- **Интерактивная физика песка и чистый драйвер GY-6500 / MPU-6050:** детерминированный программный Bit-Bang I2C драйвер 50 кГц с Clock Stretching, без деструктивного `Wire.end()` и `INPUT_PULLDOWN`. Поддержка MPU-6500 (`0x70`) и MPU-6050 (`0x68`), встроенный стенд диагностики шины I2C.
- **Энергобезопасность:** жесткий программный лимит потребления тока в **2500 мА** на уровне FastLED.

## 🛠 Аппаратная спецификация и распиновка (Pinout)

- **Микроконтроллер:** ESP32-C6 Mini (RISC-V, 160 МГц, 4 МБ Flash, Wi-Fi 6, Bluetooth 5, Zigbee/Thread).
- **Питание:** Внешний импульсный БП 5V / 3.0A.
- **Светодиодная матрица:** 16×16 WS2812B (256 LED), свернутая в цилиндр. DIN подключен снизу (`Y=0`), змейка горизонтальная, координата `X` замкнута в кольцо.

| Устройство | Назначение / Линия | Пин ESP32-C6 | Примечания |
| :--- | :--- | :--- | :--- |
| **LED-матрица 16x16** | `DIN` (Data In) | **GPIO 2** | WS2812B, резистор 330–470 Ом. Кроссфейд 500 мс, шторки 600 мс, OTA анимация |
| **Кнопка TTP223** | `I/O` (Out) | **GPIO 7** | Высокий уровень (HIGH) при касании сенсора |
| **Гироскоп GY-6500 / GY-521** | `SDA` / `SCL` | **GPIO 6 / GPIO 5** | Программный Open-Drain I2C (50 кГц) с Clock Stretching, MPU-6500/6050. Диагностика `/api/imu/diag` |
| **Микрофон INMP441** | `SCK` (BCLK) | **GPIO 18** | Тактовая линия аудио I2S |
| **Микрофон INMP441** | `WS` (LRCLK) | **GPIO 19** | Выбор аудиоканала (Word Select) |
| **Микрофон INMP441** | `SD` (Data) | **GPIO 20** | Линия данных I2S |
| **Питание компонентов** | `5V` / `GND` | `5V` / `GND` | Общая земля для всех модулей обязательна |

## 👆 Управление сенсорной кнопкой

Сенсор TTP223 скрыт в верхней крышке лампы под рассеивателем:

- **1 клик (Single Click):** Включение (плавная шторка снизу вверх за 600 мс) или выключение (плавное угасание сверху вниз за 600 мс).
- **2 клика (Double Click):** Переключение на следующий эффект по кругу ТОЛЬКО среди эффектов, отмеченных галочкой «В цикле» (`inCycle`).
- **Удержание (от 700 мс, Hold):** Плавное изменение яркости в реальном времени с нелинейным шагом (комфортно для глаза на любом уровне).
  - При удержании яркость меняется строго в одну сторону до упора (MIN: 12, MAX: 255) и не разворачивается, пока палец не отпущен.
  - При каждом следующем удержании направление меняется на противоположное.
  - **Визуальная отсечка предела:** при достижении максимума (255) верхнее кольцо лампы (`Y=15`) дважды вспыхивает белым светом. При достижении минимума (12) нижнее кольцо (`Y=0`) дважды вспыхивает бирюзовым цветом.
- **3 клика (Triple Click):** Принудительная проверка наличия обновления прошивки на GitHub (Silent OTA) с немедленной индикацией: бело-голубой радар на кольце $Y=15$, двойное зеленое мигание $Y=14..15$ («Версия актуальна»), красное мигание при ошибке или шкала 0..100% при загрузке.
- **4 клика подряд (Four Clicks):** Переключение режима радиомодуля ESP32-C6 `Wi-Fi` <-> `Zigbee` с сохранением в NVS и контрастной геометрической индикацией: горизонтальный зеленый луч-маяк сверху (Wi-Fi) или вертикальное схождение колец к экватору с пурпурно-золотой вспышкой (Zigbee / Алиса).
- **5 кликов подряд (Five Clicks):** Сброс настроек Wi-Fi и перевод лампы в режим точки доступа сопряжения (`MagicLamp-Setup`).

## 🎨 Каталог 16 встроенных эффектов

1. **Ночник (`Nightlight`):** Мягкое теплое свечение с органическим дыханием, плавной регулировкой цветовой температуры 1800K..4000K и равномерным ростом яркости от 1% до 100%.
2. **Рассвет / Закат (`DawnDusk`):** Ручной режим уютного закатного/рассветного светильника без синего спектра. (Системный Будильник «Рассвет» и Таймер сна «Отбой» вынесены в независимый глобальный планировщик, работающий поверх любого эффекта и при выключенной лампе!).
3. **Костер (`Fire`):** Вертикальные пластичные языки пламени высотой до `Y=12` на шуме Перлина без ряби, 1–2 алых уголька в темной верхушке (`Y=13..15`).
4. **Шум Перлина (`PerlinNoise`):** Бесшовные 3D-облака плазмы в полярных координатах цилиндра с регулировкой скорости движения.
5. **Игра «Жизнь» (`GameOfLife`):** Клеточный автомат Конвея с мягким органическим подсевом новых фигур при стагнации без резкого стирания поля.
6. **Аттрактор Лоренца (`LorenzAttractor`):** 3D-траектория хаотического аттрактора с неоновым шлейфом.
7. **Метаболы (`Metaballs`):** 5 упругих светящихся органических сфер, плавно взаимодействующих друг с другом.
8. **Песочные часы (`SandHourglass`):** Около 100 песчинок с реальной физикой гравитации с 6-осевого гироскопа GY-521.
9. **Реакция на звук (`AudioReactive`):** 16-полосный спектроанализатор с микрофона INMP441, взрывной динамикой во всю высоту 0..15 и круговой волной на бас.
10. **Светлячки (`Fireflies`):** 15 лесных светлячков с субпиксельными координатами, билинейным сглаживанием и индивидуальным циклом свечения.
11. **Северное сияние (`Aurora`):** Волнообразные вертикальные изумрудно-бирюзовые ленты с шумом Перлина.
12. **Матрица (`MatrixRain`):** Цифровой зеленый дождь с бегущими вертикальными шлейфами и мерцающими символами.
13. **Лава-лампа (`LavaLamp`):** Медленная тепловая конвекция крупных расплавленных восковых капель.
14. **Галактическая спираль (`Vortex`):** Вращающиеся рукава спиральной галактики, бесшовно обвивающие цилиндр.
15. **Фейерверк (`Fireworks`):** Взлетающие снизу ракеты и круговой разлет россыпи искр под действием гравитации.
16. **Киберпанк-пульс (`CyberPulse`):** Неоновые кольца Synthwave и математический волновой шейдер с динамической реакцией на звук.

## 🌐 Веб-интерфейс (WebUI — http://magiclamp.local)

При подключении к Wi-Fi перейдите в браузере: **`http://magiclamp.local`**

### Возможности интерфейса:
- **Глобальный блок «Будильник Рассвет и Таймер Отбой»:** независимая панель расписания, управляющая автовключением и затуханием лампы по времени GMT+2.
- **Интерфейс карточек-аккордеонов (Accordion UI):**
  - 16 интерактивных карточек со всеми эффектами.
  - Клик активирует эффект и раскрывает панель индивидуальных настроек (яркость, слайдер температуры света 1800K..4000K для Ночника, скорость, микрофон).
  - Чекбоксы «В цикле» (`inCycle`) для настройки переключения эффектов физической кнопкой.
- **Модуль радиомодуля Wi-Fi / Zigbee:** отображение текущего протокола радио и автоматическое переключение сессий.
- **Панель телеметрии и диагностический стенд:**
  - Время лампы (NTP GMT+2), температура CPU ESP32-C6, Wi-Fi RSSI, Uptime, Heap;
  - Кнопка **«Тест датчика»** с модальным окном аппаратной диагностики шины I2C и статусом подтяжек `gpio5_ext_pullup` / `gpio6_ext_pullup`;
  - Версия прошивки `v0.8.1`.
- **Центр обновлений (Silent OTA):** проверка обновлений с GitHub и прямая заливка `.bin` файла с защитой от коллизий.

## 📶 Первое подключение к Wi-Fi

1. При первом включении (или после 5-кратного клика) лампа создаст собственную сеть Wi-Fi: **`MagicLamp-Setup`** (без пароля).
2. Подключитесь к этой сети со смартфона или ноутбука — автоматически откроется окно авторизации (Captive Portal). Если окно не открылось, перейдите в браузере по адресу `http://192.168.4.1`.
3. Выберите вашу домашнюю Wi-Fi сеть, введите пароль и сохраните настройки.
4. Лампа подключится к роутеру и будет доступна по адресу `http://magiclamp.local`.

## 🚀 Обновление по воздуху (Silent GitHub OTA)

Лампа оснащена встроенным клиентом GitHub Releases:
- При запуске (через 30 секунд), каждые 30 минут в фоне, по 3-кратному нажатию кнопки или по клику в WebUI лампа опрашивает `https://api.github.com/repos/gaterkik/MagicLamp/releases/latest`.
- Если номер тега релиза новее текущего `FIRMWARE_VERSION` — прошивка автоматически скачивает файл `firmware.bin` в соседний OTA-раздел флеш-памяти и перезагружается.

## 💻 Сборка из исходников (PlatformIO)

### Требования:
- [PlatformIO Core](https://platformio.org/) или расширение PlatformIO для VS Code.
- Платформа Espressif 32 с поддержкой ESP32-C6 (в `platformio.ini` настроен современный `pioarduino/platform-espressif32`).

### Команды:
```bash
# Клонирование репозитория
git clone https://github.com/gaterkik/MagicLamp.git
cd MagicLamp

# Сборка проекта
pio run

# Прошивка через USB Type-C
pio run --target upload

# Монитор порта (115200 бод)
pio run --target monitor
```
